# sistem-penyetoran-hasil-jualan
Aplikasi berbasis web ini dikembangkan untuk mendigitalisasi proses pelaporan dan penyetoran uang hasil penjualan harian dari tim lapangan ke bagian administrasi/kasir. Fokus utama sistem ini adalah meningkatkan efisiensi, akurasi data keuangan, dan kemudahan dalam monitoring stok produk (seperti kopi ready-to-drink) secara real-time.
